# Звіт із практичної роботи 7

## Відомості
Автор, група, дата. Посилання на той самий власний форк, гілку practice-07,
початковий тег practice-07-base і фінальний анотований practice-07.

## Мета та середовище
Фактичні версії Python, SQLite і залежностей; синтетичні дані й локальний запуск.

## Реалізація
Схема grade_audit і тригери. Каталог файлових подій. Межа транзакції,
передавання довіреного actor_id/request_id і зв'язок із власним API №6.
Ключові фрагменти власного коду та посилання на коміти.

## Докази
Створення, фактична зміна, повтор того самого значення, відкат і відмова
без виконавця. Синтетичні витяги до/після без секретів. Зіставлення UUID
відповіді, JSONL і grade_audit. Дозволений перегляд і заборонений доступ для
кожної ролі. Паралельні звернення, ін'єкція рядка, ротація і збій файлового запису.

## Перевірки
Фактичні результати pytest, регресії №6, колекції Postman і локального
read-only перегляду. Результати не замінюйте наперед заданими твердженнями.

## Git
Щонайменше п'ять власних змістових комітів після базового тегу. Збереження
спільної історії, перевірка ignore для var/logs і відсутності секретів у поданні.

## Висновки та межі
Досягнутий результат. Відмінність аудиту SQLite і JSONL, межі ротації,
привілеїв власника сховища, серверного часу та відсутність exactly-once між сховищами.

## Джерела
Використані офіційні URL.

## Алфавітний глосарій
Терміни й абревіатури з повною англійською назвою за наявності, українським
відповідником і стислим поясненням. Це останній розділ; виноски не використовуються.
